TrackIt - Assignment Tracker
TrackIt is a web application created for the INFR3120 Web and Scripting Programming project.

TrackIt allows students to organize their school assignments in one place. Users can create assignments, enter course information and due dates, select a priority and status, and add notes about the assignment.

The Dashboard displays assignments based on their current status. Assignments are separated into To Do, In Progress, and Completed sections. The application also provides an All Assignments page and allows existing assignments to be edited.
